## 🌟 Key Features

1. **Mobile-First & Ultra-Responsive**:
   - Sticky top navigation with brand badge and mobile slide-out drawer.
   - Sticky bottom quick-action bar on mobile (`Call Now` & `WhatsApp`) for instantaneous booking conversions.
   - Floating pulsating WhatsApp button.
   - Silky smooth scroll-reveal animations using Intersection Observer.

2. **Interactive Tour Packages**:
   - Filterable categories: **All**, **Kodaikanal Special**, **Munnar Hill Stations**, **Kerala Tours**.
   - Dynamic package cards with duration, highlights, pricing estimates, and one-click quick booking autofill.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation & Run

```bash
# Install dependencies
npm install

# Start Vite development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```

---

## 🌐 Deploying to Vercel

1. Push this repository to **GitHub**.
2. Go to [Vercel Dashboard](https://vercel.com) and click **"New Project"**.
3. Import your GitHub repository.
4. Framework Preset: **Vite**
5. Build Command: `npm run build`
6. Output Directory: `dist`
7. Click **Deploy**!
